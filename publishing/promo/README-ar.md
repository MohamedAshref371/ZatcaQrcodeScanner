# إعلان قارئ فاتورة العمودي

- فيديو التطبيق الحي: `qari_fatura_youtube_short_live_ar.mp4`
- النسخة السابقة المصممة من لقطات شاشة: `qari_fatura_youtube_short_ar.mp4`
- المقاس: 1080 × 1920، بنسبة 9:16، 24 إطارًا في الثانية
- المدة: 39.25 ثانية
- الصوت: تعليق عربي رجالي فقط، دون موسيقى أو مؤثرات موسيقية
- مشاهد التطبيق في الفيديو الحي تسجيل شاشة مباشر من محاكي Android: مسح بالكاميرا، استيراد صورة، عرض النتيجة، التفاصيل، السجل، والإحصاءات. البداية والنهاية تصميم دعائي.
- بيانات الفواتير في التسجيل تجريبية، ولا تتضمن بيانات مستخدم حقيقية.

## نص التعليق الصوتي

1. فاتورتك السعودية، بياناتها بين يديك.
2. افتح قارئ فاتورة، وامسح رمز كيو آر بالكاميرا.
3. أو استورد صورة الفاتورة، أو ملف بي دي إف.
4. راجع اسم البائع، والتاريخ، والإجمالي، والضريبة بوضوح.
5. احتفظ بقراءاتك، وارجع إليها متى احتجت.
6. وتابع إحصاءات فواتيرك من مكان واحد.
7. قارئ فاتورة. اقرأ، واحفظ، وتابع.

## إعادة الإنتاج

تحتاج إلى Python وحزم `edge-tts` و`pillow` و`arabic-reshaper` و`python-bidi` داخل `_deps`، وإلى FFmpeg في PATH. شغّل:

```powershell
python publishing\promo\create_voiceover.py
python publishing\promo\build_promo.py
python publishing\promo\build_live_promo.py
```

يتطلب بناء الفيديو الحي التسجيلات الثلاثة في `work`، التي أُنشئت من التطبيق على المحاكي بأدوات `capture_live.py` و`capture_import.py` و`capture_history_stats.py`. يستخدم إنشاء التعليق الصوتي خدمة Microsoft Speech عبر الإنترنت. ملفات العمل والحزم المحلية داخل `work` و`_deps` مستبعدة من Git.
